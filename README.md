# 錢包日誌

自用的 iPhone 網頁 App：記錄每天的收支、薪資明細，以及固定支出、旅行、羽球等獨立帳。

- 資料只存在手機上（沒有伺服器、沒有帳號）。
- 可以離線使用。
- 可以直接匯入電腦版「AI記帳」的備份檔（`AI記帳備份-日期.json`）。

---

## 一、放上網路（GitHub Pages，免費）

網址只放程式，你的紀錄不會上傳，別人打開同一個網址也只會看到他自己手機上的資料。

1. 到 GitHub 建立新的 repository，名稱填 `walletlog`，選 **Public**。
2. 把這個資料夾上傳到該 repository（`docs/`、`design/` 和 `.json` 檔已列在 `.gitignore`，不會被上傳）。
3. 進入 repository 的「Settings」→ 左側「Pages」→「Branch」選 `main`、資料夾選 `/ (root)` → 「Save」。
4. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/walletlog/`

## 二、裝到 iPhone

1. 用 **Safari** 打開上面的網址。
2. 點下方的「分享」按鈕 → 往下滑 → 「加入主畫面」。
3. 之後都從主畫面的「錢包日誌」圖示打開。
4. 第一次開啟時選「匯入備份檔」，可以匯入電腦版 AI記帳 的備份檔。

> Safari 分頁和主畫面 App 的資料是分開的，請只在主畫面 App 裡記錄。

## 三、備份（很重要）

資料只存在手機上，刪掉 App 或換手機時資料就會不見。

- 「更多」→「設定」→「匯出備份檔」→ 選「儲存到檔案」→ 存到 iCloud 雲碟或 OneDrive。
- 超過 7 天沒備份，首頁會提醒你。
- 換手機時：裝好 App → 第一個畫面選「匯入備份檔」。
- 「匯出 CSV」可以用 Excel 開啟查看，但不能用來還原。

## 給之後修改程式的人

沒有建置步驟，全部是純 HTML / CSS / JavaScript，直接放上網站就能用。

| 位置 | 內容 |
|---|---|
| `index.html` | 入口 |
| `css/app.css` | 樣式（最上方是顏色、圓角、間距等設計參數，含淺色與深色兩組） |
| `js/main.js` | 分頁切換、主題、新版本偵測 |
| `js/ledger.js` | 收支計算（月合計、每日支出、分組、使用次數、備註自動完成、統計彙總） |
| `js/charts.js` | 統計圖表（直條圖、排名橫條、月曆熱度；顏色在 `css/app.css` 的 `--viz-*`、`--heat-*`） |
| `js/categories.js` | 預設分類、大類與圖示 |
| `js/store.js`、`js/db.js` | 資料存取（IndexedDB） |
| `js/legacy.js` | 電腦版 AI記帳 備份檔的轉換規則 |
| `js/backup.js` | 匯出、匯入、備份提醒、CSV |
| `js/views/` | 各畫面：明細、記一筆、統計、搜尋、標籤、更多、設定、第一次使用 |
| `sw.js` | 離線快取 |
| `tools/make_icons.py` | 產生圖示（需要 Pillow） |

**發佈新版本**：修改程式後，把 `sw.js` 和 `js/config.js` 裡的 `VERSION` 改成新的號碼，再上傳。手機打開 App 時會出現「有新版本」提示。新增 js 檔時，記得也加進 `sw.js` 的 `ASSETS`。

**改 App 名稱**：`js/config.js` 的 `APP_NAME`、`index.html` 的 `<title>` 與 `apple-mobile-web-app-title`、`manifest.webmanifest` 的 `name` 與 `short_name`。已經加到主畫面的圖示名稱，需要刪掉後重新「加入主畫面」才會更新（先備份！）。

**本機預覽**：在這個資料夾執行 `python -m http.server 8765`，用瀏覽器打開 <http://127.0.0.1:8765/>。

### 計算規則（已和使用者確認）

- 明細有三種類型：支出、收入、**退款**。退款使用支出分類，從該分類的支出扣除，不算收入。
- 本月支出 = 支出 − 退款；結餘 = 收入 − 本月支出。
- 日均支出：本月算到今天，過去的月份除以整月天數。
- 統計頁與上一期比較時，進行中的期間只比同期：本月和上月的同一段日子比、今年和去年的同樣月份比。
- 收支摘要金額預設隱藏（首頁本月卡片、統計摘要、年度收支讀數與表格），點一下顯示，切到背景自動重新隱藏；邏輯在 `js/privacy.js`。
- 年度結餘 = 固定收入 + 額外收入 − 日常支出 − 固定支出 − 旅費。固定支出（房租、孝親費）、額外收入（羽球等）、旅費只算年度，不分到月份；計算在 `js/ledger.js` 的 `yearExtras`。
- 2024–2025 只有電腦版匯入的月度彙總，可以看年度趨勢與總額，但沒有分類明細。
- 固定支出、旅行、羽球是**獨立帳**，不計入每月收支；只在年度總覽合併計算「可用金額 = 年度結餘 + Σ（額外項目收入 − 支出）」。
- 備註自動帶入：選了備註，帶入它上次用在同類型時的分類與付款方式。若這個備註用在兩種以上的餐別（早餐／午餐／晚餐／宵夜），且用過現在時段的餐別，就改用那個餐別：4:00 起早餐、10:30 起午餐、14:30–17:00 不猜、17:00 起晚餐、21:30 起宵夜。
- 薪資自動產生的收入，日期是**入帳日**（4 月薪資在 5 月入帳，就算 5 月的收入）。
- 匯入電腦版資料時，「收入＋支出類分類」的紀錄轉成退款；刮刮樂、紅包、麻將維持收入（規則在 `js/legacy.js`）。
